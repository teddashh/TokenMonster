Why it exists為什麼做這個

Usage numbers are easy to collect and easy to ignore.

用量數字好收集，也很容易被忽略。

Claude Code, Codex, Gemini CLI, and Grok Build each keep their own usage records on your machine. Adding them up takes a collector; opening the total every day takes a reason. TokenMonster pairs a local collector with characters who react to your day, and keeps both on your machine.

Claude Code、Codex、Gemini CLI 與 Grok Build 都會在你的電腦上留下各自的用量紀錄。要加總，需要收集工具；要每天打開來看，需要一點理由。TokenMonster 把本機收集器和角色放在一起：角色會依你當天的用量給反應，而且兩者都只在你的電腦上執行。

Tokens are measurements, not game currency.
Token 是量測值，不是遊戲貨幣。
How it works運作方式

Start, scan, meet, grow.

啟動、掃描、相遇、成長。

Start the desktop app or the CLI. Everything after that happens on your machine.

啟動桌面版或 CLI，之後的一切都在你的電腦上進行。

01

Start it

啟動

The desktop app lives in the system tray. The CLI starts a gateway on 127.0.0.1 and opens the dashboard through a one-time link; on a remote machine it can print the SSH tunnel command instead.

桌面版待在系統匣。CLI 會在 127.0.0.1 啟動 gateway，用一次性連結開啟儀表板；在遠端機器上，也可以改成印出 SSH 通道指令。

02

Scan local usage

掃描本機用量

The TokenTracker sidecar reads the usage records your CLIs already keep. TokenMonster accepts only totals that reconcile, and shows missing days as unavailable instead of zero.

TokenTracker sidecar 讀取各家 CLI 本來就留下的用量紀錄。TokenMonster 只接受對得上帳的總量，缺資料的日子會標成無法取得，不會當成零。

03

Meet your first sister

遇見第一位姊妹

Draw a card to see whether ChatGPT, Claude, Gemini, or Grok shows up, or pick one yourself. If one provider clearly leads your last 28 days, its sister is suggested. Switching later costs no tokens.

抽一張卡，看看 ChatGPT、Claude、Gemini、Grok 誰會來到你身邊，也可以自己挑。近 28 天如果有一家用量明顯最多，會推薦對應的姊妹。之後換人不需要多用 token。

04

Unlock from milestones

依里程碑解鎖

Seven friends unlock from provider totals, lifetime totals, active-day streaks, and how many providers you use. Each character also has 20 outfit themes that open as usage grows.

七位朋友依各家累積量、總用量、連續活躍天數，以及用過幾家 provider 解鎖。每位角色另有 20 套服裝主題，隨用量成長逐步開放。

Unlocks aren't a purchase

解鎖不是買來的

The thresholds are local measurements. A later rescan does not lock anyone again.

門檻看的是本機量到的數字。之後重掃，不會把人鎖回去。

Usage, companions, no cloud.

用量、角色，都不靠雲端。

每個畫面都在你的電腦上算出來。TokenMonster 只保存彙總後的數字，介面有繁體中文與英文。

Architecture系統架構

A gateway, a sidecar, local files.

一個 gateway、一個 sidecar，資料都在本機。

The dashboard talks only to the gateway, and only the gateway asks the sidecar for numbers. The sidecar runs with outbound network blocked.

儀表板只跟 gateway 溝通，也只有 gateway 會向 sidecar 要數字。sidecar 執行時完全不能對外連線。

Local by construction.

從設計上就留在本機。

  • Gateway and sidecar listen on 127.0.0.1 only
  • gateway 與 sidecar 只監聽 127.0.0.1
  • The sidecar starts with an allowlisted environment, no usable PATH, and network calls blocked
  • sidecar 啟動時只帶白名單內的環境變數，沒有可用的 PATH，網路呼叫也會被擋下
  • Raw usage JSON is parsed in memory and dropped; only aggregates are kept
  • 原始用量 JSON 只在記憶體中解析，用完就丟，只保存彙總數字
  • Prompts, file names, paths, and raw model IDs stay out of logs, share cards, and diagnostic bundles
  • prompt、檔名、路徑與原始 model ID 不會進入 log、分享卡與診斷包
  • Leaving your machine always takes an explicit action: the media pack, BYOK chat, or an update check
  • 要連到外部，一定是你主動操作：下載素材包、BYOK 聊天或檢查更新

頁面不直接讀紀錄

Design decisions設計取捨

Why it is built this way.

為什麼這樣做。

01

Wrap TokenTracker, do not fork it

包住 TokenTracker，不 fork

Finding tools, parsing changing log formats, and deduplicating records is TokenTracker's job. TokenMonster pins one exact version, runs it as a sidecar behind a narrow adapter (ADR 0005), and re-audits the output before moving to a new one.

找出工具、解析一直在變的紀錄格式、去除重複，都交給 TokenTracker。TokenMonster 鎖定單一版本，以 sidecar 跑在精簡的 adapter 後面（ADR 0005），要升級前先重新稽核它的輸出。

02

Character media is a separate, consented download

角色素材另外下載，要你同意

The install carries starter art for the four sisters and 168 text lines, and works offline. The full pack (891 images and 55 voice clips, about 73 MB) downloads only after you agree, is checked against SHA-256 digests, and can be repaired or removed. Voice is off by default.

安裝檔只帶四位姊妹的初始立繪與 168 條文字台詞，離線就能用。完整素材包（891 張圖與 55 段語音，約 73 MB）要你同意後才下載，逐一比對 SHA-256，也可以修復或移除。語音預設關閉。

03

Directory-local install, exact toolchain

裝在資料夾裡，版本鎖死

The CLI tarball installs into its own folder and carries a shrinkwrap, so the sidecar's dependencies cannot drift. A global npm install breaks on a bundled-dependency quirk, so it is not supported.

CLI 的 tgz 安裝在自己的資料夾裡，附帶 shrinkwrap，sidecar 的相依套件不會被升到沒審查過的版本。npm 全域安裝會碰到 bundled dependency 的問題，所以不支援。

You choose what leaves

要出去，得你點頭

Scans stay on this computer. Each way out waits for you.

掃描留在本機。往外的每條路，都等你自己打開。

Limits and not yet

限制與尚未完成

  • The Windows installer is not code-signed, so SmartScreen warns on first run
  • Windows 安裝檔還沒有程式碼簽章，第一次執行時 SmartScreen 會警告
  • The desktop app is Windows-only; macOS and Linux get the CLI
  • 桌面版只有 Windows；macOS 與 Linux 目前只能用 CLI
  • The CLI accepts only Node.js 24.15.0 with npm 11.12.1 and is not on the npm registry
  • CLI 只支援 Node.js 24.15.0 搭配 npm 11.12.1，也還沒上架 npm registry
  • Updates are manual: automatic checks are off by default, and both update feeds returned 404 on 2026-10-01
  • 更新要手動下載：自動檢查預設關閉，而且 2026-10-01 查核時，兩個更新來源都回應 404
  • The opt-in contribution counter is in the code, but its service is not deployed
  • 選用的匿名貢獻計數器已經寫在程式裡，但服務端還沒部署
  • CI fails at the complete dependency audit, which reports 3 high findings, all from image-size through electron-installer-dmg and appdmg. @electron/packager 20.3.0 removed public extract-zip, and the shipped-dependency audit passes. On Windows, Unix mode checks are skipped because Windows has no POSIX modes and Node reports 0666 and 0777. The vault relies on the permissions of its folder. The desktop default is %APPDATA%\TokenMonster\secrets. A custom folder, set with Electron's --user-data-dir, must be private to the user. The CLI keeps the chat key in memory. Contribution files are written only when a credential host is injected, under .tokenmonster/contribution-v2 in HOME, or in the user profile home when HOME is unset. That directory must be private to the user too.
  • CI 失敗在完整相依套件稽核，回報 3 個 high，都來自 image-size（經由 electron-installer-dmg 與 appdmg）。@electron/packager 20.3.0 已不再帶入公開的 extract-zip；出貨相依套件的稽核則通過。Windows 沒有 POSIX 模式，Node 會回報 0666 與 0777，所以 Unix 模式檢查在 Windows 上略過。保險庫依賴它所在資料夾的權限。桌面版預設是 %APPDATA%\TokenMonster\secrets。若用 Electron 的 --user-data-dir 改位置，自訂資料夾必須只有該使用者能讀寫。CLI 的聊天金鑰只放在記憶體。只有另外接上 credential host 時，才會把貢獻憑證寫進 HOME 底下的 .tokenmonster/contribution-v2；沒有設定 HOME 時則寫在使用者主目錄。那個目錄也必須只有該使用者能讀寫。
